# SearchShelf：Notepad++ 搜索收藏

适用于 Windows x64 Notepad++。插件自动加载，按 Ctrl+F 打开搜索窗口即可使用。

## 全宽收藏列表版（2026-11-09）

收藏功能区现在位于原生“查找模式／正则表达式”区域下方，不再紧贴搜索输入框。

- 收藏列表占满整个底部区域，展示“关键词”和“描述”，支持局部滚动和调整列宽。
- 已移除独立的“关键词查看”框。关键词列默认使用约 65% 宽度，描述列使用约 35%。
- 单击只高亮选中，不改动搜索框或描述；双击某条收藏才填入原搜索框，并显示该条的可编辑描述。
- 按住 Ctrl 单击可增减不连续的选择，按住 Shift 可连续选择；点击“删除”会提示选中条数，确认后批量删除。
- 底部可编辑描述，保存原搜索框的关键词；另有删除、导入和导出。
- 原生“选取范围内”、透明度滑块和收起按钮不再由插件移动。右侧收起按钮现在只控制新增收藏区的显示／隐藏，不再触发 Notepad++ 原生精简模式。

“选取范围内”是 Notepad++ 自带功能，勾选后仅在编辑器已选中的文本范围内查找，并不是收藏列表的选择范围。

新增区域使用原生选项控件的字体（包含列表、表头、标签、描述输入框和按钮），背景使用 Windows 当前 TAB 主题的填充色；深色模式从原搜索窗口读取颜色。重新显示窗口或主题／DPI 变化后重新同步。实际 Notepad++ 视觉效果尚未截图验收。

## 关键词与描述筛选

收藏列表上方提供两个独立筛选框，分别对应关键词和描述。输入部分文字即可实时筛选，支持中文和不区分大小写的英文；使用字面包含匹配，正则符号（如 `.+`、反斜杠）当作普通文字。两框同时填写时，必须同时满足两个条件。

“清除筛选”会清空两个条件并恢复全部收藏，右侧显示“当前结果 / 总条数”。单击仅选中，双击才填入搜索框。Ctrl／Shift 多选和批量删除在筛选结果中仍有效，只删除当前选中的记录，未显示的收藏会保留。更改筛选条件时清空原列表选择，避免误删。

筛选只影响显示，不会修改配置；导出仍包含全部收藏。修改描述或导入后会重新应用当前条件，因此不匹配的条目会从当前结果中隐藏，可清除筛选查看。

已通过模拟窗口回归：中文、英文大小写、复杂表达式字面匹配、双条件交集、无结果与清除条件，以及筛选后的双击填入、修改保存、批量删除和未匹配记录保护。窗口缩放、收起、字体和已有配置测试继续通过。

## 自由调整窗口大小

已解除原生固定高度及上下边缘拖拽限制，可以从上下边框和四角调整窗口大小。收藏区展开时，新增高度会分配给收藏列表，描述和操作按钮跟随底部。保留最小宽高以避免控件重叠；收起收藏区只隐藏新增功能，再展开恢复收起前的列表高度。

“选取范围内”仍保留：它可以限制查找只作用于编辑器中选中的文字；没有选中范围时通常灰显。

## 收藏区独立收起修复

按钮命令由插件接管，只隐藏或显示底部收藏区，窗口高度随之调整，上方搜索选项不切换布局。启动时若检测到旧版保存的原生精简状态，会先恢复原生完整搜索布局。收藏数据、双击填入、Ctrl／Shift 多选与批量删除继续保留。

## 其他布局处理

移除了旧版对全部原生控件的还原／位移操作，以及整个搜索窗口的 WM_SETREDRAW 暂停。插件仅在底部增加独立子窗口，保留原生布局；显示窗口时请求完整背景刷新，避免旧区域残留。解除 Notepad++ 原生最大高度锁定，仅限制安全最小高度，并按实际窗口高度计算收藏列表大小。

绘制、输入和滚动消息不会触发布局。按初始窗口 DPI 及 DPI 变化缩放，接入官方深色模式接口。

## 安装或升级

1. 保存编辑的文件，完全退出所有 Notepad++ 窗口。
2. 解压安装包，把其中的 `SearchShelf` 文件夹放到 Notepad++ 安装目录的 `plugins` 下。升级时替换其中的 DLL。
3. 示例目标路径：`C:\Program Files\Notepad++\plugins\SearchShelf\SearchShelf.dll`。
4. 重启 Notepad++，按 Ctrl+F。

不能装到 32 位或 ARM64 版。系统可能要求管理员权限。原来的收藏配置不需要删除或修改。卸载时完全退出 Notepad++，删除插件的 `SearchShelf` 文件夹即可。

## 保存和共享

在原搜索框输入关键词，在收藏区填写描述，点击“保存”。相同关键词再次保存会更新描述。“导出”生成 `.ini` 文件；其他人安装插件后点“导入”即可使用。导入合并新关键词，重复关键词保留本地描述。

配置保存在 Notepad++ 返回的插件配置目录，文件名 `SearchShelf.ini`。安装版通常位于 `%APPDATA%\Notepad++\plugins\config`。保存失败会提示并保留原收藏，格式损坏时不会覆盖。最多 1000 条，每条关键词最多 4096 字，描述最多 512 字。仅保存关键词和描述，正则／大小写等选项仍使用原搜索窗口当前设置。

配置为 UTF-16，字段以 `v:` 开头，使用 `\s` 表示空格、`\\` 表示反斜杠，`\n`、`\r`、`\t` 表示控制字符。建议通过导入导出共享。`examples/SearchShelf.ini` 是示例。

## 验证和兼容性

已通过 DLL 加载／导出接口与中文配置读写测试。模拟宿主回归测试验证：上下边缘与角落拖拽命中、自由高度变化、列表随高度增长、最小高度保护及收起后恢复调整过的高度；7000 次绘制／输入／滚动／移动消息不移动原生控件；30 次隐藏显示与尺寸事件不改变原生位置，不暂停全窗口绘制；重新设置原生高度不会累积高度；20 次收藏区收起／展开循环保持原控件位置不变，收起后重开搜索窗口仍保持隐藏；模拟旧版原生精简状态启动时能恢复完整搜索布局；250 条收藏可局部滚动，单击不填入、双击填入对应行；多选批量删除能持久化，保存失败保留数据与选择；全宽列表、移除查看框、原生字体和表头字体同步均已验证。

真实 Notepad++ 的视觉效果仍需在目标版本、主题与缩放比例下验证，模拟测试不能替代实际交互验收。插件仍依赖官方源码中的窗口控件 ID；并非官方提供的搜索窗口嵌入扩展点。

## 编译

解压 Zig 0.13.0 Windows x64 到 `tools/zig-windows-x86_64-0.13.0`，运行 `powershell -ExecutionPolicy Bypass -File .\build.ps1`，将生成 DLL 并运行配置与布局测试。

接口依据：[官方插件通信文档](https://npp-user-manual.org/docs/plugin-communication/)、[官方搜索窗口控件定义](https://github.com/notepad-plus-plus/notepad-plus-plus/blob/master/PowerEditor/src/ScintillaComponent/FindReplaceDlg_rc.h)。官方调研源码仅保存在本地 `reference/`，不纳入本仓库；插件实现位于 `src/`。
